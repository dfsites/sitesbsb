Meu site está lento: causas comuns e o que fazer

As causas mais comuns de lentidão em sites de empresas, como medir a velocidade de forma correta e o que fazer para deixar o site mais rápido.

Por Equipe Sites Brasília

Site lento é um problema silencioso. O dono da empresa acessa pelo computador do escritório, com o site já em cache, e acha que está tudo bem. Enquanto isso, o cliente abre pelo celular, na rua, espera alguns segundos olhando para uma tela em branco e volta para o Google para clicar no concorrente. Ninguém reclama de site lento; as pessoas simplesmente vão embora.

Como saber se o site está lento de verdade

Não confie só na sua impressão. Faça testes mais próximos da realidade do cliente:

  • Teste no celular, usando dados móveis, e não no Wi-Fi do escritório.
  • Use uma janela anônima, para o navegador não aproveitar arquivos já guardados.
  • Use ferramentas de medição, como o PageSpeed Insights do Google, que mostra uma nota e aponta problemas específicos.
  • Veja os dados reais no Google Search Console, no relatório de Core Web Vitals, que reúne a experiência de visitantes de verdade. Explicamos essas métricas em Core Web Vitals para empresas.

Teste mais de uma página: a inicial, uma página de serviço e uma de contato. Às vezes só uma delas tem problema.

As causas mais comuns

1. Imagens pesadas

É a causa número um em sites de empresas. Fotos tiradas com câmera ou celular são enviadas direto para o site, com tamanho muito maior do que a tela precisa. Uma única imagem de banner pode pesar mais que o resto da página inteira.

O que fazer: redimensionar as imagens para o tamanho em que aparecem, comprimir e usar formatos modernos, como WebP ou AVIF. Também vale configurar o carregamento sob demanda, em que imagens mais abaixo na página só carregam quando o visitante chega nelas.

2. Excesso de plugins e scripts

Em sites WordPress, cada plugin adiciona código. Fora do WordPress, o mesmo acontece com scripts de terceiros: chat, pop-up, pixels de anúncios, mapas, widgets de redes sociais, ferramentas de análise. Cada um é mais um arquivo que o navegador precisa baixar e executar.

O que fazer: listar tudo o que está instalado, remover o que não é usado e questionar o que é pouco usado. Muitas vezes, três ferramentas fazem a mesma coisa.

3. Tema ou construtor visual pesado

Temas “multiuso” e construtores de página de arrastar e soltar são práticos, mas costumam carregar muito código que o seu site nem usa. O resultado é uma página inchada, mesmo com pouco conteúdo.

O que fazer: otimizar o que for possível. Em casos extremos, a solução definitiva pode ser refazer o site numa base mais leve. Vale comparar as alternativas de plataforma antes de decidir.

4. Hospedagem fraca ou sobrecarregada

Em hospedagens compartilhadas muito baratas, dezenas ou centenas de sites dividem o mesmo servidor. Se um deles consome recursos demais, todos sofrem. O sinal típico é o tempo de resposta do servidor alto: o site demora para começar a carregar, antes mesmo de mostrar qualquer coisa.

O que fazer: avaliar se o plano atende ao site e considerar uma hospedagem melhor dimensionada. Veja hospedagem barata ou gerenciada.

5. Falta de cache

Sem cache, o servidor monta cada página do zero a cada visita, consultando o banco de dados sempre. Com cache, uma versão pronta é entregue rapidamente.

O que fazer: ativar cache no servidor ou por plugin, e configurar o cache no navegador para arquivos que mudam pouco, como imagens, fontes e folhas de estilo.

6. Sistema desatualizado

Versões antigas do PHP, do WordPress ou de plugins costumam ser mais lentas, além de mais vulneráveis.

O que fazer: manter tudo atualizado, com backup antes de cada atualização e teste depois.

7. Fontes e vídeos mal carregados

Várias famílias de fontes, com muitos pesos diferentes, e vídeos incorporados logo no topo da página atrasam a exibição do conteúdo.

O que fazer: usar poucas fontes, carregar só os pesos necessários e exibir vídeos com uma imagem de capa que só carrega o player quando o visitante clica.

8. Site comprometido

Uma lentidão repentina, sem nenhuma mudança da sua parte, pode indicar que o site foi invadido e está sendo usado para outras finalidades. Se for o caso, veja site invadido ou com vírus.

Tabela de diagnóstico rápido

Sintoma Causa provável
Demora para começar a aparecer qualquer coisa Hospedagem, falta de cache, servidor distante
Texto aparece, imagens demoram muito Imagens pesadas ou não otimizadas
Página aparece, mas trava ao rolar ou clicar Excesso de scripts e plugins
Conteúdo “pula” enquanto carrega Imagens e anúncios sem espaço reservado
Ficou lento de repente Atualização recente, plugin novo ou invasão
Lento só no celular Imagens grandes, scripts pesados, tema não otimizado

Por que velocidade importa

  • Visitante: quanto mais demora, mais gente desiste antes de ver o conteúdo.
  • Anúncios: se você paga por clique, cada visitante que desiste antes de a página abrir é dinheiro perdido.
  • Google: a experiência da página faz parte dos critérios do buscador. Velocidade sozinha não garante posição, mas site lento atrapalha.
  • Credibilidade: um site travado passa a impressão de empresa desatualizada.

O que não fazer

  • Instalar mais um plugin “de velocidade” em cima de dez outros sem entender a causa.
  • Otimizar só para a nota da ferramenta e esquecer a experiência real no celular.
  • Apagar conteúdo importante para ganhar alguns pontos.
