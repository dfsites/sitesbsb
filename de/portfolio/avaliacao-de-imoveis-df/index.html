Avaliação de Imóveis DF

Website zur Kundengewinnung für Immobilienbewertung, Wertgutachten und technische Stellungnahmen im Bundesdistrikt (DF), mit eigenem Panel zur Verwaltung der Anfragen.

Website besuchen

Kontext

Professionelle Immobilienbewertung in Brasília, bei der jede Anfrage eine Geschäftschance ist.

Herausforderung

Die vorherige Version war eine Single-Page-Anwendung, die Inhalte nur per JavaScript anzeigte – das erschwert Google das Lesen. Kontaktanfragen hatten keinen geordneten Ort, an dem sie verfolgt werden konnten.

Ziel

Die Website mit vollständigem, indexierbarem HTML neu aufbauen und jede Anfrage in einen erfassten, nachverfolgbaren Lead verwandeln.

Lösung

Neuaufbau in Astro mit statischen Seiten, einem Formular, das Anfragen in einer Datenbank speichert, und einem eigenen Admin-Panel zur Verfolgung jedes Leads.

Architektur

  • Astro 7 für statische Seiten
  • PHP-Endpunkte für das Formular
  • MySQL-Datenbank für die Leads
  • Admin-Panel mit Login

Funktionen

  • Kontaktformular mit Speicherung in der Datenbank
  • Panel mit Status, Notizen und CSV-Export
  • WhatsApp-Button mit eigener Nachricht für jede Leistungsseite

SEO

  • Suchintentions-Map pro Seite
  • Ausdrückliche Regel gegen doppelte Seiten pro Stadtviertel (Anti-Doorway)
  • Automatische Prüfung von Links, H1, Title, Description, Canonical, strukturierten Daten und Sitemap

Automatisierungen

  • Qualitätsprüfungs-Skript vor jeder Veröffentlichung, inklusive Suche nach offengelegten Geheimnissen im Code
  • Deployment mit Server-Backup vor jeder Veröffentlichung

Ergebnis

  • Website von SPA auf indexierbares statisches HTML migriert
  • Leads zentral in einem eigenen Panel
  • Veröffentlichungsprozess mit automatischer Prüfung und Sicherung
