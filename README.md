# sitesbsb — build publicado de sitesbrasilia.com.br

Este repositório contém **somente o build** (saída de `astro build`) do Sites Brasília V2,
publicado automaticamente na KingHost via webhook a cada push na branch `main`.

Não edite arquivos aqui diretamente: o código-fonte fica no projeto `--sites-brasilia-novo`.
Configuração do backend (`sb-config.php`) fica no servidor, fora do document root, e nunca é versionada.
